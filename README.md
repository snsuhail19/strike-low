# STRIKE//LOW — low-end multiplayer FPS prototype

## Run locally
1. Install Node.js 18+.
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm start`.
5. Open http://localhost:3000 in two browser tabs.
6. Use the same room code in both tabs, or use Quick Match.

## What is included
- Browser FPS-style multiplayer prototype
- Quick matchmaking
- Room create/join
- 4 weapons: pistol, SMG, rifle, shotgun
- Real-time player movement over WebSocket
- Health, hits, kills and respawn
- Lightweight canvas renderer designed for low-end hardware
